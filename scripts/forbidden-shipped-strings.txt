# Forbidden strings in the SHIPPED npm tarball — internal personas, codenames,
# and the maintainer's name/home path. The published package is what a stranger
# sees in their node_modules; these must NEVER appear in it.
#
# SCOPE: this guards the TARBALL, not the source tree. Internal names in a
# developer comment in src/ are fine — removeComments keeps them out of dist,
# and what lives in the repo for humans is a separate question from what ships.
#
# FORMAT: one JavaScript regex per line. Blank lines and #-comments ignored.
# Every pattern matches CASE-INSENSITIVELY (loadPatterns compiles it with the i flag).
# Adding a future persona/codename is ONE line here — no code change.
# `\b` word boundaries keep a name from matching INSIDE a longer word: the owner name
# with a prefix or a suffix, the role name at the start of a longer word.
# tests/shipped-surface-persona-free.test.ts pins both directions. (The public GitHub
# handle never contains the owner name, so it is not a boundary case.)
